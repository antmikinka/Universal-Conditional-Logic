Two ways to show a model its tools

One side is handed the JSON schema. The other side is handed the name and a short line about what the tool does. The schema can stay on the computer that checks the call.

One run

Matrix 20260809T040554Z. One seed. Qwen3.6-35B. 408 cells. No transport errors. Pass rate here means the scorer accepted the call, not a claim that native tools are incapable.

Names tied the lean signatures on pass rate and used fewer tokens than the pasted schema. The full schema did not buy accuracy on this suite. Native tools picked the right tool family often and lost ground on the argument check. Average latency sat around 32 to 37 seconds. The shorter catalog was not the faster one.

What this does not say

It is one seed. Multi-tool scenarios were the hard cells. A July harness that labeled one arm “UCL” was the arm that pasted the schema into the prompt, and that arm used more tokens than a name list plus native tools=. The label and the cheap format are not the same thing.

The converter turns a pasted OpenAI or MCP list into the name-list lines and counts the characters. The host still has to check the arguments. This page does not do that check.
