The model reads the name. The schema stays on the host.

Universal Conditional Logic is a specification language for prompts, and a way to show tools as a short name list instead of pasting every JSON schema into the model.

Blog The prompt study, then the tool-call matrix. Two results, kept apart. Converter Paste an OpenAI or MCP tool list. Read the name list and the character count. Builder Write a prompt, pick from 71 tools, and run Convert against your model.

Specification study

The preprint measured prompt specification. The reported token cut is 29.8%. The design is 13 models, 7 conditions, 4 iterations. The analysis file is marked N=305. The peak sits at S* ≈ 0.509. That number is not a tool-calling score.

Name list

On one seed of Qwen3.6-35B, 408 cells, a names-only catalog passed 85.4% at about 2,374 tokens. The pasted schema passed 84.4% at about 4,307 tokens. Native tools on that scorer passed 66.7%, with a high name match and a weaker argument match. Less text. Not a faster answer.
