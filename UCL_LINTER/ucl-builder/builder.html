About UCL

Universal Conditional Logic Framework

UCL is a mathematical framework for AI prompt optimization based on empirical research (N=305, p < 2.89×10⁻¹³).

Key Principles:

  • Always use [[CRITICAL:]] - +9.3% quality bonus
  • Keyword-based CONDITIONS - Lower structural overhead
  • Avoid SWITCH statements - High O_s penalty
  • Optimal specification - S* ≈ 0.509

Core Syntax:

  • {{concept:name:attribute}} - Concepts
  • [[TYPE: content]] - Directives
  • ^^CONDITION^^ - Conditionals
  • <section>...</section> - Sections
  • [[TOOL: name]] - Tool references
  • {{UCL_TOOLS}} - Tool placeholder (78% overhead reduction)

Tool Integration:

Switch to the Tools tab in the sidebar to select from 71 pre-built tools across 9 domains (filesystem, web, database, API, MCP, shell, Playwright, Chroma, ClearThought). Tools use keyword-conditional activation for minimal overhead.
